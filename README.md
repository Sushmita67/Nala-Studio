# Nala Studio Platform

A modern, responsive beauty salon management platform built with React, TypeScript, and Tailwind CSS. This collaborative project by **Ashish Mool** and **Sushmita Bishwakarma** provides a comprehensive solution for beauty salon operations, customer management, and online booking.

## 🌟 Features

### 🎨 **Modern UI/UX Design**
- **Responsive Design**: Fully responsive across all devices (mobile, tablet, desktop)
- **Dark/Light Theme**: Seamless theme switching with persistent preferences
- **Nala Brand Colors**: Custom color palette with pastel beauty studio theme
- **Smooth Animations**: CSS transitions and micro-interactions for enhanced UX
- **Accessibility**: WCAG compliant with proper ARIA labels and keyboard navigation

### 💅 **Beauty Services Management**
- **Comprehensive Service Catalog**: Nail care, lash extensions, beauty treatments, special occasions
- **Service Categories**: Nails, Lashes, Pedicure, Facial, Massage
- **Add-on Services**: Customizable add-ons for each service
- **Pricing Management**: Dynamic pricing with add-on calculations
- **Service Duration Tracking**: Built-in duration management for scheduling

### 📅 **Advanced Booking System**
- **Multi-Step Booking Process**: 4-step guided booking experience
- **Real-time Availability**: Dynamic calendar with available time slots
- **Staff Selection**: Choose preferred technicians or auto-assign
- **Nepal Phone Validation**: Localized phone number validation and formatting
- **Booking Confirmation**: SMS notifications and confirmation system
- **Reschedule/Cancel**: Easy booking modifications

### 👥 **Customer Management**
- **User Authentication**: Secure login/registration system
- **Customer Profiles**: Personal information and preferences management
- **Booking History**: Complete booking records and status tracking
- **Favorite Technicians**: Save preferred staff members
- **Customer Dashboard**: Personalized dashboard with booking overview

### 🎁 **Loyalty & Rewards System**
- **Points System**: Earn points with every service
- **Membership Tiers**: Basic, Premium, and VIP membership levels
- **Reward Redemption**: Redeem points for discounts and free services
- **Membership Benefits**:
  - Basic: 5% discount, birthday special, newsletter access
  - Premium: 15% discount, free add-ons, priority booking, monthly gift
  - VIP: 25% discount, all add-ons included, exclusive events, personal stylist

### 🏢 **Admin Dashboard**
- **Comprehensive Analytics**: Revenue tracking, booking statistics, performance metrics
- **Staff Management**: Add, edit, and manage staff profiles and schedules
- **Service Management**: Create, edit, and manage service offerings
- **Inventory Management**: Track salon supplies and low stock alerts
- **Booking Management**: View, edit, and manage all customer bookings
- **Real-time Monitoring**: Live dashboard with today's appointments

### 📱 **Responsive Features**
- **Mobile-First Design**: Optimized for mobile devices
- **Touch-Friendly Interface**: Large touch targets and swipe gestures
- **Progressive Web App**: Fast loading and offline capabilities
- **Cross-Platform Compatibility**: Works seamlessly on all browsers and devices

### 🎨 **Theme & Branding**
- **Nala Studio Branding**: Custom logo integration (light/dark variants)
- **MerakiUI Integration**: Modern UI components and design system
- **Custom Color Palette**:
